# Adam + L2 vs AdamW — Reproducible Experiments

Research-oriented PyTorch benchmark contrasting **coupled L2 regularization** (`torch.optim.Adam(weight_decay=λ)`) against **decoupled weight decay** (`torch.optim.AdamW(weight_decay=λ)`).

Experiment code, dataset guides, reproducible plots, and tests are being added on a feature branch.
